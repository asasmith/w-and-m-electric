# AGENTS.md

## Skill usage (mandatory)

Before acting on any request, check whether a skill applies. If one applies, use it — do not skip directly to implementation.

- New feature / page / component → `spec-driven-development`, then `planning-and-task-breakdown`
- Any multi-file change → `incremental-implementation`
- Building or modifying UI → `frontend-ui-engineering`
- Forms, auth, or Sanity write paths → `security-and-hardening`
- Bug or unexpected behavior → `debugging-and-error-recovery`
- Before merging any change → `code-review-and-quality`
- Slow pages, large bundles → `performance-optimization`
- Every commit → `git-workflow-and-versioning`

Confirm which skill you're applying before generating files.
